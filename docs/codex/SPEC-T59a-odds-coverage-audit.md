# SPEC-T59a (P0): 歴史単勝オッズ被覆監査 (read-only)

起票: 2026-07-19 (Fable 5)。T59討議合意の実行第1弾。
**読み取り専用** — ability.db への書き込み・スクレイプ・本番変更は一切しない。

## 1. 目的

T59の基礎確率 (単勝市場確率 = 最終オッズ逆数の正規化) が2021-2026H1の全期間で
組めるかを確定する。オッズ源は `runs.win_pay` の符号化 (勝馬=払戻円÷100、
他馬=括弧付きオッズ) で、**復元は既存 `backtest_win5.py` の `parse_final_odds()` を
唯一の正とし、独自パーサを書かない** (実装分岐を作らない)。

## 2. 集計 (年別 2021, 2022, 2023, 2024, 2025, 2026H1)

1. **全馬復元率**: rank IS NOT NULL の出走行のうち、オッズ復元に成功した行の割合
2. **全馬完備レース率**: レース内の全出走馬が復元成功したレースの割合。
   **評価母集団 (8頭以上) とWIN5母集団 (9R以降・土日) の2通り**で出す
3. **欠損理由の分類**: win_pay NULL / 形式不一致で復元失敗 / その他 — 件数と代表例10件
4. **系統性の確認**: 欠損が場・月・取得経路 (TARGET由来 vs netkeiba埋め戻し) に
   偏っていないか (T51で発見したソースドリフトと同型の偏りを疑う)
5. **市場確率の健全性**: 完備レースについて Σ(1/odds) の分布 (=控除率込みブック合計)。
   年別に中央値・5/95パーセンタイル、想定帯 (概ね1.15〜1.45) を外れるレースの列挙
   (外れ値はオッズ復元バグの検出器として使う)

## 3. 品質確認

- 無作為10レースについて、win_pay生文字列 → 復元オッズ → Σ(1/odds) を目視で突合し
  報告に添付
- 実行時の ability.db sha256 を報告に記載 (現在の封印値 `ea6b…f061` のはず。
  T51 Stage Cが先に実行された場合は新hashを記載し、その旨明記)

## 4. ゲート (上位モデル判断の材料)

- 目安: 各年の**完備レース率 ≥99% (評価母集団)** なら基礎確率は成立
- 未達の年がある場合は停止して報告 — 埋め戻し (netkeiba) の要否・規模は上位モデルが
  別途判断する (このタスクでは実施しない)
