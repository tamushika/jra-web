# SPEC-T61a: T16棚卸し+市場比較 (好走馬予測精度向上ロードマップ第1弾)

起票: 2026-07-23 (Fable 5)。T61討議合意 (docs/T61-accuracy-roadmap-discussion.md) の実行第1弾。
**読み取り専用の集計・比較のみ** — T16モデル・本番ファイル・通知経路には一切触れない。

## 1. 目的

T16 (Web用複勝確率モデル、2026-07-14採用・オッズ非依存) は現行Web主成分スコアには
勝っているが、**市場 (単勝オッズ由来の複勝確率) やCL由来の複勝確率とは未比較**。
この比較で「T16が市場に対しても独立情報を持つか」を確認する。独立情報があれば
T16b (連対専用モデル) やT53/T54の投資判断の土台になり、無ければ「T16の価値は
Web表示の校正のみ」という結論になる。

## 2. 比較対象 (3つ・同一母集団)

1. **T16**: `web_place_model.json` (2021-24学習・2025校正のPlatt、7頭以下2着内ルール)
2. **市場複勝**: T59cと同一定義 (単勝オッズ逆数正規化→λ2=λ3=1の素朴Harvilleで複勝確率、
   ブック帯[1.15,1.45]・8頭以上フィルタ)
3. **CL由来複勝**: 現行conditional logit (win5_ml_model.json、T45切替後のcandidate)
   の勝率から同じ素朴Harvilleで複勝確率を導出

## 3. 母集団・分割 (T59cと同一規約に揃える)

- 分割: 学習/校正期間は各モデルの既存artifact (2021-24学習・2024/2025校正等) を
  そのまま使う。**比較自体は2024選抜・2025固定・2026H1固定の3期間で行う**
  (T59cの評価枠組みを流用)
- 母集団: ブック帯[1.15,1.45]・8頭以上 (7頭以下はT59cの教訓どおり別集計、
  または対象外として明示)
- 3モデルとも**同一レース集合**で比較すること (T16はオッズ非依存だが、比較のためには
  単勝オッズが揃う=ブック帯内のレースに絞る必要がある)

## 4. 指標

- 一次: 各モデルのtop3 (複勝的中) Bernoulli log loss (レース内平均、T59c/T16と同一定義)
- 副: Brier・捕捉率 (上位1/3/5)・校正曲線
- **残差相関**: T16の予測確率と市場/CL予測確率の残差 (実現値−予測) の相関係数を
  券種横断で報告。相関が低いほど独立情報がある可能性を示す (ただし相関の解釈は
  上位モデルが行う。本SPECは数値報告のみ)

## 5. 制約

- **一次指標を決めて選抜構成を変えない** (単一構成の比較であり、探索ではない)
- 3モデルいずれの再学習・再校正もしない (既存artifactをそのまま評価に使う)
- 本番表示・通知経路には触れない

## 6. テスト

1. 3モデルの母集団が完全一致すること (レースIDセットの一致assert)
2. 各モデルの複勝確率導出が定義どおり (合成データで既知値と照合)
3. 残差相関の計算が正しいこと
4. `python -m pytest tests/ -q` 全体パス

## 7. 成果物

`docs/T61a-t16-market-comparison-report.md` + 結果JSON。台帳登録は不要
(モデル改善の実験ではなく比較集計のため)。解釈と次段階 (T16b/T53/T54優先順の
最終確定) は上位モデルが行う。0.5-1日想定。
