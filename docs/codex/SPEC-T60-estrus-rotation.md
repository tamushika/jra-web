# SPEC-T60: H2 春牝馬の中3週ローテ×発情周期 — Stage A監査

起票: 2026-07-19 (Fable 5)。出典: T57仮説トリアージ H2 (docs/T57-hypotheses.md、
書籍p40-43)。**本文書の設計は数値を見る前に固定した事前登録である** (Stage Aは
read-only監査のため台帳登録はしないが、判定基準の事前固定は同じ流儀で行う)。

## 1. 仮説 (機構)

馬の性周期は約21日 (繁殖期≈1〜8月)。中3週ローテ (前走から約28日) は「前走=性周期上の
強いフェーズ → 本番=発情期」に嵌まりやすく、**春の牝馬・中3週・前走好走の馬は市場評価
対比で系統的に凡走しやすい**。中2週 (約21日=1周期ちょうど) は前走と同フェーズ。

## 2. 事前固定の定義 (Stage A監査)

- 期間: 2021-01-01〜2026-06-30 全体 (監査であり分割しない)。8頭以上・rank非NULL
- **対象**: 牝馬・レース月1〜8月
- **間隔グループ** (前走からの日数): 中2週=15〜21日 / **中3週=22〜28日 (仮説群)** /
  中4-6週=29〜49日 (参照)。中1週以下 (≤14日) と50日以上は除外 (別要因が大きい)
- **前走好走の条件付け**: 前走3着内 (書籍の「前走で強く見えた馬」の操作化)
- **統制**: ①同一条件の牡馬・セン馬 (春・同間隔) ②牝馬の9〜12月 (非繁殖期・同間隔)
- **主指標 (DiD)**: 人気帯 (1-3, 4-8, 9+) 層別の複勝実現率について
  (春牝・中3週 − 春牝・中2週) − (春牡・中3週 − 春牡・中2週)。
  副: 非繁殖期牝馬をベースにした同型DiD、単勝の市場キャリブレーション残差
  (T59a方式のブック帯[1.15,1.45]レースのみ・実現勝率 − 市場含意勝率)
- **判定基準 (事前固定)**: 仮説を「有望」とするのは、①前走3着内サブセットで
  主DiDが負 (凡走方向) かつ開催日ブロックbootstrapのp<0.10、②人気帯横断で方向一致、
  ③非繁殖期DiDでは効果が消えるか大幅減衰、の3点が揃った場合のみ。
  1点でも欠ければ「本実験に進まない」— サブセットの入れ替え・基準の緩和はしない
- 出力: `docs/T60-estrus-audit-report.md`。DB書き込み・スクレイプなし
