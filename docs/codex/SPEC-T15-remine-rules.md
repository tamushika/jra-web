# SPEC T15: mined rules の再採掘 (発見2021-23 / 選抜2024)

共通指示: [README.md](README.md) 参照。タスク管理: docs/TASKS.md の T15。
背景理論: docs/prediction-accuracy-improvement-roadmap.md §3.3、§4.8。

## 背景
自動採掘ルール (`mine_criteria.py` → `mined_rules.csv`、買い273/消し86) は、
発見・選抜の期間に2025〜2026年を使っており、2025固定テストがリークしている。
「発見2021-23 / 選抜2024」に組み直して再採掘し、クリーンなルールセットの
2025/2026H1 OOS成績を測る。**Codexは実装と数値報告まで。採否は上位モデル。**

## 要求仕様
1. `mine_criteria.py` を読み、現行の発見期間・選抜期間・選抜基準 (該当数下限、
   複勝率閾値等) を報告に明記する。
2. 期間を「発見2021-01-01〜2023-12-31 / 選抜2024-01-01〜2024-12-31」に変更できる
   ようにする (引数化推奨: `--discover-to 20231231 --select-from 20240101 --select-to 20241231`)。
   選抜基準のパラメータは現行値を変えない (期間だけの効果を測るため)。
3. 出力は **`mined_rules_v2.csv` へ保存 (本番 `mined_rules.csv` は上書きしない)**。
4. 評価: 既存のmined rules評価ハーネス (backtest系でmined_rules.csvを使っている箇所を
   特定して流用) で、以下を2025年・2026H1それぞれで比較:
   - 現行 mined_rules.csv (リークあり) の該当馬成績
   - mined_rules_v2.csv (クリーン) の該当馬成績
   - 指標: 買いルール該当馬の複勝率・単勝/複勝回収率、消しルール該当馬の同指標、
     ルール数と該当件数
   - 注意: 現行ルールの2025年成績は「選抜に使った期間での成績」なので見かけが良くて
     当然 — その旨を報告に注記する (真の比較は2026H1)
5. 検証: 再採掘の実行ログ (ルール数の変化)、既存テストが壊れないこと

## 受け入れ基準
- mined_rules_v2.csv が生成され、本番CSVが不変
- 期間別・ルールセット別の比較表が報告される
- 再実行可能 (同じコマンドで同じ結果)

## やらないこと
- 本番 mined_rules.csv / criteria_weights.json の差し替え (採否判断後の別作業)
- 選抜基準パラメータのチューニング
- 血統条件を含む採掘 (T23で別途。本タスクは期間の組み直しのみ)
