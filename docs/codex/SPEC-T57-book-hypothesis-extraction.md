## 2. Stage 0: 対象章の転写 (実装者)

1. 対象は**第1・2・9・11章の約64ページのみ** (全222ページのOCRはしない)
2. OCRは**ローカルollama (qwen系vision)** を使う: 無料・netkeiba/Gemini日次制限と
   無関係・日またぎ不要。旧 `ollama_pdf_extractor.py`
   (`old/20260719/root/` に隔離中) を土台に再利用してよい
3. 出力: 章ごとのプレーンテキスト (ローカル `data/t57/`・gitignore対象)。
   表 (第1章の定点観測表など) は崩れてよいがページ番号を必ず付す
4. 転写品質の確認: 各章2ページを目視突き合わせ (数値の transcription error は
   仮説トリアージを誤らせるため)
5. スクレイプ・外部送信・本番ファイル変更なし

## 3. Stage 1: 仮説トリアージ (上位モデル)

転写を読み、仮説候補を `docs/T57-hypotheses.md` に整理する。各仮説に:
①主張とページ参照 ②検証に必要なデータ (既存/要収集) ③検証設計の素案
(どの馬券種・どの特徴・どのゲート) ④事前期待値、を付す。
**個別の検証はここでは行わない** — 有望仮説はユーザー承認のうえ別タスクとして
起票し、実験は通常どおりT39台帳登録を経る。
