# SPEC T10: M4-B 過剰人気/過小人気の限定補正 (T11の後に着手)

共通指示: [README.md](README.md) 参照。タスク管理: docs/TASKS.md の T10。
背景理論: roadmap §4.3 M4-B。前提知見: M4-A (確率校正) は不採用 —
市場確率は全体としては良く校正されている (2026-07-13)。残る仮説は
「特定条件の馬だけ市場が系統的に間違える」で、それを少数の特徴で限定補正するのがM4-B。

**T11のoffset付きconditional logit実装を必ず再利用する** (M4-B = 同じ構造で
特徴セットを「市場の間違い方」に特化した少数に絞ったもの)。
**Codexは実装と数値報告まで。採否は上位モデル。**

## 要求仕様
1. `backtest_ml.py` に `--m4b` を追加。スコア = ln(market_prob) + w·z (offset固定はT11と同一)。
   補正特徴 z は以下の**8個以内**に限定 (すべて build_dataset で計算可能なことを確認し、
   できないものは除外して報告):
   - prev_rank_pop_gap: 前走着順 − 前走人気 (前走で人気より走った/凡走した)
   - prev_rank (前走着順そのもの)
   - layoff: ln_interval (休み明けの過剰嫌気/過剰評価)
   - class_up: 昇級初戦フラグ
   - m2_gap: M2順位 − 市場順位 (T12のNO_MARKET_FEATURESモデルで算出したレース内順位差)
   - pop_conc: レースの上位人気集中度 (1番人気市場確率 − 2番人気市場確率)
   - field_size: 頭数 (標準化)
   - fav_flag×prev_rank: 1番人気×前走凡走の交互作用
2. 過補正防止 (roadmap §4.3):
   - L2正則化 (2024でλ選択、T11と同じグリッド)
   - **1頭あたり補正幅キャップ**: |w·z| を定数c (2024で c ∈ {0.1, 0.2, 0.4} から選択) でクリップ
3. 分割・報告はT11と同一形式 (M0 / 現行CL / M3 / M4-B の4行比較、top-k/LogLoss/Brier、
   フロア検証、順位入替率)。
4. 追加報告: 補正が効いた条件の内訳 — 係数の符号と大きさ、および
   「入替が発生したペアの的中改善/悪化の件数」(補正の当たり外れの実数)
5. テスト: キャップ動作の単体テスト (クリップ境界で順位保存が壊れないこと)

## 受け入れ基準
- 4モデル×2期間の比較表と係数表
- M4-BがM0を下回る場合もそのまま報告 (それが答え)
- --write 禁止。既存挙動不変。全テストパス
