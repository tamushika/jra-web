# SPEC-T19: 母父・血統交互作用の少数連続特徴 (事前固定・強収縮)

起票: 2026-07-19 (Fable 5)。トリガー「T41/T18より下の優先度」は両タスク完了 (共に負の結果)
により発火。**T23の離散ルール再採掘の再来は禁止** — 事前固定した少数の連続特徴のみを検証する。
実装者の担当は数値報告まで。**評価実行はStage 0通過後に上位モデルがT39台帳へ登録してから**。
採否は上位モデル。

## 1. 仮説と位置づけ

採用済み `sire_pts` (父の産駒as-of成績) が持つ情報の延長として、**母父 (BMS) と
文脈適性 (芝ダ・距離帯・道悪)** に市場が織り込み切れていない残差があるか。
市場相対モデル改善は全滅済み (roadmap §3) のため、期待値は控えめ。
ゲートは通常どおり市場フロア+paired bootstrap。

## 2. Stage 0: データカバレッジ確認 (最初に実施・未達なら停止)

1. pedigree cache (`pedigree_cache.json`、T23/血統バックフィルの成果) における
   **父・母父の充足率を年別 (2021-2026H1) に報告**する (ability.db の出走馬に対する被覆率)
2. いずれかの年で**母父被覆率が80%未満なら停止して報告** (上位モデルが縮小案を判断)
3. 読み取りのみ。スクレイプによる追加取得はこのタスクではしない (netkeiba日次制限を
   他タスクと取り合わないため。不足があれば別途バックフィル起票)

## 3. 特徴 (6列固定・組合せ探索なし)

as-of集計は既存 `sire_pts` と同じ規約 (レース日より前の走のみ・T33 as-of断面・
fold統計provider再利用) に従う。収縮は w = n/(n+k) で全体平均へ:

1. `bms_surface_pts`: 母父×当該surface (芝/ダ) の産駒as-of複勝率offset
2. `bms_dist_pts`: 母父×距離帯 (sprint ≤1400 / mile 1401-1800 / route >1800、T44と同じ帯) の同上
3. `sire_dist_pts`: 父×距離帯の同上 (既存sire_ptsは文脈無差別のため帯別を追加検証)
4. `bms_wet_pts`: 母父×道悪 (稍重以下) の同上。**良馬場レースでは0** (文脈整合)
5. `bms_available` / `bms_wet_available`: availability flag 2列 (欠測は0+flag)

計6列。上記以外の血統列・離散ルール・組合せは**追加禁止**。

## 4. 評価 (T39プロトコル準拠)

- T41ハーネス (`backtest_feature_pack.py` 隔離パック) を再利用。
  **本番FEATURES・本番ファイル不変**、パックOFFで決定論SHA一致
- 分割: 学習2021-23 / 選抜2024 / 2025・2026H1 historical benchmark固定報告
  (21-24 final refit + 21-23学習版併記)
- グリッド: baseline L2{0.3,1,3} + 血統6列 k{50,200,800}×L2{0.3,1,3} = **12候補**
  (血統集計はnが小さいセルが多いため強収縮側を含む)
- 一次指標 = 勝馬LogLoss (2024選抜)。副 = Brier・top-k・市場フロア・WIN5開催日paired・
  **surface別/距離帯別/馬場状態別の増分内訳** (仮説どおり文脈側で効くかの確認)
- 台帳登録時に ability.db と pedigree cache 双方の sha256 を封入する

## 5. テスト

1. as-of: 当該レース日以降の走が集計に入らない (合成データ)
2. 収縮単調性: n増加でwが単調増加・n=0で0
3. 道悪特徴が良馬場レースで恒等0
4. パックOFF決定論SHA一致・`python -m pytest tests/ -q` 全体パス
