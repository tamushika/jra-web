## 1. 要件A: 全期間表示に日別成績グラフ

日付フィルタなし (全期間) のとき、日別実績セクション (`daysSection`) の直上に
日付×成績のグラフを表示する。

### 1.1 API (`collect()`)

- 全期間時のみ、応答に `series` を追加する:
  ```json
  "series": {
    "models": [{"app":..,"model":..,"version":..,"config":..,
                "points":[{"date":"YYYY-MM-DD","settled":n,"win_rate":..,"tan_roi":..,"fuku_roi":..}, ...]}],
    "ev":     {"points":[{"date":..,"settled":n,"win":..,"tan_roi":..,"fuku_roi":..}, ...]},
    "win5":   {"points":[{"date":..,"hits":k,"total":m,"win5_hit":bool}, ...]}
  }
  ```
- `series` は**日数上限なし** (既存 `days[:90]` / `daily[:60]` は表と互換のため不変)。
  ソースは既存の `out_daily` / `ev_by_date` / `win5_by_date` の再整形のみで、
  新規SQLは追加しない
- `?date=` 指定時は `series` を含めない (従来応答は完全不変)

### 1.2 表示

- **外部ライブラリ・CDN禁止** (現状の素のJS/HTML構成を維持、オフラインで動くこと)。
  手書きSVG (またはcanvas) で棒/折れ線を描く
- コントロール:
  - 系列セレクタ: モデル群 (summaryと同じ `app / model 版 (config)` 表記) + 「EV通知」+「WIN5」
  - メトリクストグル: 単勝的中率 / 単勝回収 / 複勝回収 (WIN5系列は的中数/対象数固定)
- 回収率表示時は **100%基準線** を引く。settled=0 の日は欠測として描かない (0と区別)
- 各点に `title` ツールチップ (日付・対象n・値)。**点クリックでその日の日付フィルタへ遷移**
  (既存daysテーブルの日付クリックと同じ挙動)
- 横軸は開催日のみを等間隔に並べる (非開催日の空白を作らない)。ラベルは適度に間引く

## 2. 要件B: レース別結果の日付グループ化 (+で展開)

### 2.1 API

- 全期間時: `race_details` は**最新日付の行のみ**返す (現行の `[:300]` capはこの変更で
  事実上撤廃)。加えて日付ごとの集計 `race_dates` を追加:
  ```json
  "race_dates": [{"date":"YYYY-MM-DD","races":n,"settled":n,"win":n,"top3":n,
                  "tan_roi":..,"fuku_roi":..,"models":m}, ...]  // 日付降順・全日
  ```
  (`models` = その日の予測モデル群数。集計は既存 `daily` の日付方向の再集計で、
  race_details と同一母集団 = スコア1位馬基準)
- `?date=` 指定時: 従来どおりその日の全行を返す (**応答形不変**)

### 2.2 表示

- 全期間時のレース別テーブル:
  - **最新日付**: 見出し行 (日付+件数+的中サマリ) の下に従来の行を**展開済み**で表示
  - **それ以前の日付**: `<details>`/`<summary>` による折りたたみ1行
    (`＋ 2026-07-12 (24R 確定24 単勝的中6 回収82.5)` の形式。開くと `＋`→`−` 相当の
    ネイティブ表示。既存 `.w5-detail` と同じパターンでよい)
  - **遅延読込**: 展開時に `api/perf?date=<日付>` をfetchし、その応答の `race_details` で
    行を描画する。同一セッション内は日付→行HTMLをMapでキャッシュし再fetchしない。
    読込中は「読み込み中…」、失敗時はエラーメッセージを行内に表示 (握りつぶさない)
- 日付フィルタ表示時は従来どおりのフラットなテーブル (変更なし)

## 3. テスト (tests/test_jra_perf.py に追加)

1. 全期間応答: `series.models` の点が `daily` の同日同群と一致・日数上限がないこと
2. 全期間応答: `race_details` が最新日付のみ・`race_dates` の日付降順と件数集計が
   レース詳細と一致すること
3. `?date=` 応答: `series`/`race_dates` を含まず、既存キー・値が回帰しないこと
4. settled=0 の日の win_rate/roi が None のままであること (0.0 と混同しない)
5. 既存テスト全パス (`python -m pytest tests/ -q`)
