# SPEC-T65: 条件セル監査 — 特殊条件下の市場効率の系統検証 (反証フィルタ)

起票: 2026-08-03 (Fable 5)。[討議収束記録](../T65-pinpoint-cell-discussion.md) の9点合意を
執行可能な形に固定する。**位置づけは反証フィルタ**: 7セル全てに負のpriorがあり、
期待値は「全滅」。全滅でも「セル単位の市場効率マップ」として恒久価値を持つ。

**実装者 (Codex) の担当は監査ハーネスの実装・テスト・実行・報告まで。
数値の解釈・familyの通過裁定・prospective起票判断は上位モデルのみ。**

## 1. 一次量とモデル

- レースrの一次量: `d_r = market勝馬LogLoss − model勝馬LogLoss` (正=モデル優位)
  - model確率: T62/T42b評価と同一のbacktest CL機構 (2024評価は2021-23学習、
    2025/2026H1評価は2021-24 refit)。**本番artifactは使わない** (学習期間の
    in-sample楽観を避けるため、各期間がOOSになる既存の凍結分割そのまま)
  - market確率: ability.dbの確定単勝オッズの1/odds正規化 (T62歴史層と同一)
- 対象母集団: T62と同一 (平地・8頭以上・全馬オッズあり) ∩ 2024/2025/2026H1

## 3. ゲート (凍結)

- **Δ_min = 0.0042805** (T62公表表 docs/T62-race-selection-report.md の
  2024選定0.017398・未選定0.008837の差の1/2。転記のみ・再計算禁止)
- family F の二重ゲート (一次判定・pooled 2024+2025+2026H1):
  1. 絶対優位: `E[d|F] > 0`
  2. 集中効果: `θ_F = E[d|F] − E[d|Fᶜ] > Δ_min` (Fᶜ=同時期の非familyレース)
- **開催日blockで6片側仮説 (3family×2条件) を同時再標本化 (2,000回) し、
  maxT補正後に両方を満たしたfamilyのみ通過**。Holmは感度分析として併記
- 必須の追加フィルタ (通過familyに対して):
  - 3期間 (2024/2025/2026H1) の `E[d|F]` 同符号
  - family内の市場top-kフロア (k=1..4、model coverage ≥ market coverage) が
    pooled期間で非悪化
- セル単独 (C1〜C7) の有意性はゲートにしない。全セルの2種効果量 (E[d|c]・θ_c)・
  負のprior・階層縮約順位 (θ̂_ct ~ N(θ_c+u_ct, s_ct²), θ_c ~ N(0,τ²)) を参考報告
- セル診断で重複ペアの片側のみ二条件を満たした場合、共有レース除外後の
  残差セル符号を必須報告 (追加ゲートにはしない)
