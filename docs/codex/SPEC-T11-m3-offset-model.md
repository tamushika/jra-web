# SPEC T11: M3 市場offset+残差モデル (T33の後に着手)

共通指示: [README.md](README.md) 参照。タスク管理: docs/TASKS.md の T11。
背景理論: roadmap §4.2。2026-07-13の再検証で現行CL (ln_odds を自由係数で学習) は
2026H1で市場に劣後すると判明した。M3は log(市場確率) を**係数固定のoffset**にして
残差だけを学習する構造で、「残差係数→0 なら市場と完全一致」というフロア保証を持つ。
市場劣後の現状ではこのフロア保証こそが主目的。

**Codexは実装と数値報告まで。採否は上位モデル。**

## 要求仕様
1. `backtest_ml.py` に `--m3` を追加:
   - スコア = ln(market_prob_i) + w·x_i (market_probはレース内正規化1/odds、
     offsetは係数1.0で固定し最適化対象にしない)
   - x_i は NO_MARKET_FEATURES (T12で定義済みの ln_odds 抜き20特徴量)
   - conditional logit の尤度最適化に offset 項を組み込む (fit_conditional_logit を
     offset対応に拡張。既存呼び出しの挙動は不変に保つ)
   - **L2正則化を残差係数にかけ、強度は2024調整データで選ぶ** (候補: λ ∈
     {0.01, 0.1, 1, 10, 100}/n 相当のグリッド)。λ→大で市場一致に近づくことを確認
2. 統計ソースは T33 の ability.db 由来経路を使う (T33完了が前提。未完なら現行統計で
   実行し、その旨明記)
3. 分割: 学習2021-23 / 調整2024 (λ選択) / 固定テスト2025 / 確認2026H1
4. 報告 (同一集団・全行併記): M0人気 / 現行CL / M3。top-k (1..4)、レースLogLoss、Brier。
   加えて **M3のフロア検証**: 各期間でM3のtop-kがM0を下回っていないか
   (下回るなら正則化選択の失敗 — その事実も報告)
5. レース内で市場順位からの入替が起きた率 (レースあたり平均入替ペア数) も報告
   (M3がどれだけ「動かしているか」の観測)
6. テスト: offset付きCLの単体テスト (offsetのみ・残差0で市場確率を厳密再現すること)

## 受け入れ基準
- M0/現行CL/M3 × 2期間の完全な比較表
- 残差係数→0 の極限で市場一致が数値検証されている
- --write 禁止 (併用エラー)。既存フラグの挙動不変。全テストパス

## やらないこと
- 特徴量の追加 (相対特徴量はT13。まず既存20特徴でM3構造の価値を測る)
- 本番接続
