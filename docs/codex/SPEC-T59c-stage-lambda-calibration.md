## 1. 入力と母集団 (T59aで確定)

- 市場確率: `runs.win_pay` → `parse_final_odds()` (唯一の正・独自パーサ禁止) →
  レース内 1/odds 正規化
- **母集団フィルタ: Σ(1/odds) が帯 [1.15, 1.45] 内のレースのみ** (同着・非完走の
  ブック不完全を統一除外、~1.4%/年。T59a追補が根拠)。加えて従来の8頭以上
- 分割: **λ適合=2021-23 / 一次評価=2024 / historical benchmark=2025・2026H1**
  (再調整禁止)

## 2. モデル (自由度は λ2, λ3 の2つだけ)

割引Harville (Lo-Bacon-Shone型)。市場勝率 p を所与として:

- P(2着=j | 1着=i) = p_j^λ2 / Σ_{k≠i} p_k^λ2
- P(3着=k | 1着=i, 2着=j) = p_k^λ3 / Σ_{l≠i,j} p_l^λ3
- λ2=λ3=1 が素朴Harville (=ベースライン)。1着段階は市場確率そのまま (校正しない)

**λの適合は段階別に分離可能**: λ2は「実現した2着馬の条件付き尤度」、λ3は
「実現した3着馬の条件付き尤度」をそれぞれ2021-23で最大化する (MLE・1次元最適化×2)。
**券種は一切見ない** (券種別の選択自由度ゼロ)。適合値と対数尤度カーブ
(λ=0.5〜1.2の断面) を報告する。

## 3. 券種確率と一次指標 (台帳は券種別に3実験)

適合λを凍結し、同一のλで3券種の確率を導出する:

| 券種 | 事象の定義 | 一次指標 (2024・開催日ブロック) |
|---|---|---|
| 複勝 | 馬iが複勝圏内 (**8頭以上=3着内、7頭以下=2着内**) | 馬単位Bernoulli log lossのレース平均 |
| ワイド | 組(i,j)の両方が3着内 (全組合せをmulti-label Bernoulli扱い) | 組単位Bernoulli log lossのレース平均 |
| 馬連 | 実現した1-2着のunordered組 | レース単位 -log P̂(実現組) |

- 各券種: **候補=適合λ vs ベースライン=λ2=λ3=1 の2候補のみ**。
  paired bootstrap (eval/blocks.py・開催日ブロック) で差とp値
- 副指標: Brier・校正曲線 (確率10分位ごとの実現率)・人気帯別内訳・
  2025/2026H1のhistorical benchmark固定報告
- 三連複 (top3 unordered set の -log P̂) は**参考報告のみ** (第2波の判断材料。
  台帳登録しない)
