# SPEC T18: 騎手/厩舎ローリング成績 (直近状態の階層収縮特徴)

共通指示: [README.md](README.md) 参照。タスク管理: `docs/TASKS.md` の T18。
背景: [RE-accuracy-ideas-20260717.md](RE-accuracy-ideas-20260717.md) §5-B1 (採用済み)。
起票: 2026-07-18 上位モデル。

**実装者の担当は実装・テスト・数値報告まで。採否・台帳登録・コミットは上位モデル。**

## 1. 目的

既存 `j_pts`/`f_pts` は長期の静的/as-of統計であり「直近の調子」を持たない。
長期能力 (事前分布) と直近状態を分離した収縮推定を追加し、増分を検証する。

## 2. 特徴定義 (ability.db のみ・レース日より前のas-of更新)

対象エンティティ: 騎手 (jockey)、調教師/厩舎 (利用可能な列で判定。無ければ
騎手のみで実施し、その旨を報告)。

- `j_roll30` / `j_roll90`: 直近30/90日の複勝率を長期率へ収縮した値
  `(hits + k·prior) / (n + k)`。prior = その騎手の長期as-of複勝率
  (履歴無しは全体平均)。kは§4のグリッド
- `j_roll_n30` / `j_roll_n90`: ln(1+騎乗数) (状態の信頼度)
- 調教師についても同形 (`t_roll30` 等)
- **騎手×調教師の組は特徴にせずcoverage報告のみ** (RE §5: 組は薄く危険。
  n分布を報告し、特徴化は次版で判断)
- 全集計はレース当日を含めない (前日まで)。未来リーク禁止

## 3. 実装方式

T41と同じ隔離パターン: `PACK_FEATURES` 方式で本番 `FEATURES` 不変、
`backtest_feature_pack.py` のハーネスを再利用 (T41実装後に着手)。
パックOFFで決定論SHA一致。

## 4. 評価 (T39プロトコル準拠・実行前に上位モデルが台帳登録)

- 分割: 学習2021-23 / 選抜2024 / 2025・26H1はhistorical benchmark (固定)
- グリッド (台帳登録時に確定): 収縮k ∈ {10, 30, 100} × L2 ∈ {0.3, 1, 3} ×
  構成 {騎手のみ, 厩舎のみ, 両方} = 27候補以内
- 一次指標: 勝馬Log Loss (2024)。副: Brier・top-k・市場フロア・WIN5開催日paired
- **最大の落とし穴 = 少騎乗の見かけ高率** (RE §5)。騎乗数階級別
  (n30 < 5 / 5-20 / 20+) の係数寄与とcalibrationを報告する
- benchmarkは2024選抜構成の21-24 final refit (21-23学習版併記)

## 5. テスト

1. as-of: 当日・未来の騎乗が集計に入らない (合成履歴)
2. 収縮: n=0でprior値、n増加でraw率へ単調接近
3. 30/90日窓の境界 (ちょうど30日前のレースの包含規則を固定し明記)
4. パックOFF決定論SHA・`python -m pytest tests/ -q` 全体パス
