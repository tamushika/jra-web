## 特徴定義とcoverage

- 6列固定: `bp_connect_s`, `bp_connect_a`, `bp_nonconnect`,
  `bp_same_course`, `bp_connect_available`, `bp_nonconnect_available`
- 既存tfeatと同じ直近4走、基準タイム差、馬場差、recency重みを使用
- 同一コースはS/Aから除外して `bp_same_course` へ分離
- グラフ参照率: 95.5-99.0%、connect available: 70.0-74.6%、
  nonconnect available: 62.4-64.0%。全flagは非定数
- standardized係数（2021-24 refit）の絶対値は全て0.019未満。
  `bp_connect_s=-0.0041`, `bp_connect_a=+0.0180`, `bp_nonconnect=-0.0178`,
  `bp_same_course=-0.0123`で、Sランクの符号は仮説方向と整合しない

ability.dbには内外回り列がないため、コース名の `内/外` を場+芝ダ+距離へ固定射影した。
影響対象は各期間の1.4-4.2%。射影後にS/Aが重なる6グラフ行はS優先とした。この制約は
`outputs/t58_result.json` の `graph_audit` とcoverageへ記録している。
