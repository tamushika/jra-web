## 仮説一覧 (推奨順)

### H2: 春牝馬の「中3週」ローテ×発情周期 ★推奨 (本書で最も価値ある仮説)

- **主張** (p40-43): 馬の性周期は約21日 (繁殖期は概ね1〜8月)。中3週ローテ (前走の
  約28日後) は「前走が性周期上の強いフェーズ→本番が発情期」に嵌まりやすい巡り合わせ。
  したがって**春の牝馬で中3週・前走好走の馬は、前走ベースの市場評価に対して系統的に
  凡走しやすい**。中2週は前走と同フェーズで前走どおり走れる。例: フィリーズレビュー組
  の桜花賞不振 (中3週) vs チューリップ賞組 (中4週)、ヴィクトリアマイル中3週組
  【2-0-2-10】
- **新規性**: 機構 (LHサージ・エストラジオール動態) が具体的で、格言として流布して
  いない。JRA採血研究 (現役牝馬も性周期は正常に回っている) が前提を支える
- **必要データ**: 既存で完結 (性別・出走間隔・月・前走着順・人気)
- **検証設計素案**: サブグループを機構から事前固定 (牝・1〜8月・間隔22〜28日) し、
  市場人気に対する複勝実現率の系統差を監査 (read-only)。有望なら凍結分割+prospective
  で台帳登録。**過去のM系 (市場相対の探索的残差掘り) と違い、サブグループが機構により
  先験固定される点が本質**
- **事前期待値**: 中。市場相対の残差は全滅してきた前歴があるが、これは探索でなく
  単一の事前仮説

### H1: ケントク買いの定点観測と一般化 (P5系・T59の歪み3系統に整合)

- **主張** (p29-32): 七夕賞の枠連7-7は同義馬連に対しシェア比2倍以上を毎年維持
  (1992-2023の30年表・電投シフト後も不変・コロナ無観客でも不変) = **構造的な過剰投票の
  実証例**。逆に「統計的裏付けのない有名ジンクス」(例: フェブラリーS初ダート、検定
  p=26%で棄却不能) はファンが避ける分だけジンクス破り側が過小評価される可能性
- **一般化仮説**: 日付連動レース (7/7前後の七夕賞等) の枠連ゾロ目は恒常的にEV劣後。
  ジンクス銘柄の逆張りは「ジンクスの検定p値」で層別すれば検証可能
- **必要データ**: **枠連オッズ (未取得)** — T59b (オッズボードPoC) の調査対象に枠連の
  取得可否を含めると一石二鳥。ジンクス逆張り側は個別レース定義が必要で操作化コスト高
- **検証設計素案**: P5 (限定歪み検証・prospective専用) の第1号として枠連ゾロ目のみ
  登録。ジンクス逆張りは事前リスト固定ができるまで見送り
- **事前期待値**: 機構は明確だが機会が少ない (年数回)。買いではなく「買わない/
  裏を取る」知識としての価値が主

### H3+H4: 夏は小兵 (ベルクマン則) + 夏は牝馬 (1実験に同居可)

- **主張** (p44-45): 熱交換効率は体サイズの逆数に比例 → 夏は軽量馬有利・冬は大型馬
  有利。著者集計 (古馬1勝C芝5-7F) では夏の勝ち馬平均463.8kg vs 冬475.8kg (全体の
  体重シフト考慮後も有意と主張)。**「冬は大型」は経験的に知られるが「夏は小兵」は
  格言未定着 → 織り込み不足の余地**。(p34-36) 「夏は牝馬」はJRA総研検証済み
  (場形態と独立・新馬未勝利でも成立) だが有名 → 織り込み濃厚
- **必要データ**: 既存 (馬体重・月・距離・surface・性別)。精緻化するなら気象庁の
  当日気温 (無料) で月proxyを置換
- **検証設計素案**: T41様式の小特徴パック (体重偏差×暑熱、性別×暑熱の2列+flag) で
  1実験。特徴路線全滅の前歴に照らし期待値は控えめ
- **事前期待値**: 低〜中 (H3側に一分の狙い目・H4は検証済み=織り込み済みの公算)

### H5: 斤量の物理的非影響 → 市場の斤量過大評価の監査

- **主張** (p190-199): 斤量差の力学的影響は無視可能 (加速時0.23N/kg・淀の坂で
  0.01kcal/kg・感覚量は最軽量馬でも最大2.6%・故障リスク増も路盤0.84mm相当で無視可)。
  一方、市場・ファンは「1キロ1馬身」等で斤量を重視 → **ハンデ戦の高斤量馬が系統的に
  過小評価されている可能性**
- **整合**: 我々のT41 (A8ハンデ系特徴) 不採用と方向一致 — 斤量は予測に効かない。
  残る問いは「市場が効かないものを効くと信じて価格を歪めているか」
- **必要データ**: 既存 (kinryo・人気・複勝実現率)。ただし2026年kinryo欠損はT51 Stage C
  完了が前提
- **検証設計素案**: 監査 (read-only): ハンデ戦の斤量帯×人気帯で市場キャリブレーション
  残差を集計。系統差があればP5へ
- **事前期待値**: 低〜中 (市場は案外正しく無視している可能性が高いが、監査は安い)

### H6: 凍結防止剤×冬ダート×含水率 (T50資産の再利用・低優先)

- **主張** (p189): 冬ダートは塩化カルシウム+食塩の凍結防止剤で凝固点降下+蒸発抑制 →
  「晴れても乾きにくい」= **含水率の意味が冬ダートだけ別物**
- **設計素案**: T50測定DB (2,363行・保持済み) の冬ダート限定複合。T50本体不採用のため
  再挑戦には新規登録+明確な事前限定が必要
- **事前期待値**: 低 (T50が全体で無効だった以上、サブセットで蘇る公算は小さい)

## 非仮説として記録 (負の知識・追わない)

- **冬毛割引は無効** (p46-49): 全馬が冬毛をまとう+能力減シナリオ不在。歴史的には
  厩務員の仕事熱心さのproxyだった可能性
- **「フケ」の外見判断は不可能** (p37-39): 担当者の「フケ判断」と採血性周期は統計的に
  無関係。パドック所見のシグナル化は追わない (H2は外見でなくローテ×暦で機構を突く点が別)
- **「夏負け」の下見所判断も同様に不可** (p50-51)
- **ジンクスの統計検定手法** (p16-29: 帰無仮説・検定p値・背景シナリオ必須) は
  本プロジェクトのT39流儀と完全一致 — 方法論的裏書き
- **運用ノート**: 2024年〜新潟の昼休み時程 (p158) — 時刻系特徴・スナップショット
  運用でレース時刻分布が年次で変わる点に注意。周回コース外回しロス2πt (1m外≒3馬身/周,
  p202-203) と新潟千直の外ラチロス≤半馬身 (p200-201) は表示・解説用の背景知識
