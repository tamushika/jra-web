## 3. 裁定と根拠

**決定: 通知閾値 1.3 を維持 (引き下げを採用しない)。**

1. **事前登録の棄却規則を適用**: 「校正比が 1 を大きく下回る閾値帯は回収率以前に棄却」により
   1.10 / 1.15 / 1.20 は棄却。1.05 も 0.846 と劣化。
2. **EV の大小が質を並べていない**: 校正比は閾値を上げるほど単調に悪化する
   (1.00: 0.969 → 1.05: 0.846 → 1.10: 0.235 → 1.15: 0.000)。EV 閾値は「高いほど良い馬を選ぶ」という
   前提で作られているが、この prospective 窓ではその前提が**反転**している。閾値という仕組み自体が機能していない。
3. **1.00 の ROI 110% は edge の証拠にならない**: 95% CI [62.4%, 172.6%] が損益分岐 (100%) を跨ぎ、
   18 勝/121 件と薄い。勝ちは 1-3 番人気帯に集中 (14/54) し、4-8 番人気帯は 3/51。
   EV による選別の付加価値ではなく人気馬の素の勝率を見ている可能性が高い。
4. したがって閾値を下げても、**裏付けのない「買い推奨に見える通知」が月 46 件増えるだけ**になる。
   購入推奨は採用ゲートを通るまで行わない方針 (senior-model-handoff §4) と整合しない。

機械的な棄却規則で残った 1.00 を採用しない判断は上位モデルの裁定権限の範囲 (登録時に「現状維持を含む」と明記)。
事後に基準を追加したのではなく、登録済みの一次指標の**構造 (単調悪化)** を根拠としている。

## 4. 得られた知見 (負の結果として記録)

- **モデルの EV は、その大きさで質を並べられない。EV が高い帯ほどモデルは勝率を過大評価する。**
  これは 2026-07-13 の「市場のレース内序列に系統的な隙は無い」(M 系全滅) と整合し、
  勝率モデルが市場同等〜劣後であることの通知側からの再確認でもある。
- 閾値 1.3 は新モデル (T45) の EV 分布の下で 25 開催日・715 レース中 **1 件も発火しない**。
  EV 通知は事実上停止した状態にある。これは不具合ではなく、分布と閾値の関係の帰結。
