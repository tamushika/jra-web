## 実装した固定特徴

対象レースより前の日付にある、各馬の直近4有効走のみを使用する。2走未満は個体特徴を0、
`sectional_available=0`とする。同日の先行レースを含む当日結果は一切使わない。

| 特徴 | 定義 |
|---|---|
| `early_position_asof` | 先頭コーナー通過順位÷頭数の直近平均 |
| `late_gain_asof` | (着順−最終コーナー順位)÷頭数の直近平均。負値は順位を詰めたことを示す |
| `measured_pace_fit_asof` | 過去走の実測前半ラップを、日付atomicな同場・同馬場・同距離水準で正規化し、序盤位置との中心化交互作用を平均 |
| `field_pace_projection_asof` | 同レース各馬の過去走由来序盤圧力の平均 |
| `sectional_available` | 上記個体特徴を2走以上から算出できた場合1 |

ラップ水準は同日全レースの比率を計算してから日末に履歴へ追加する。空コーナー配列、
取消・除外・中止、`runs`に対応しない行、異常な通過順位は履歴に使わない。
`agari`とラップ末尾3Fの差は診断専用であり、モデル特徴には含めていない。

### 裁定: 不採用 (REJECTED)

本実験は**T61時代の全候補中で最も強い棄却候補**である。2024選抜自体でbaselineに勝ち
(T54aが失敗した関門)、T53を落とした人気帯再分析を生き残り、実測ラップ特徴は既存特徴と
ほぼ直交 (r=-0.02)、という過去の不採用候補になかった3つの強みを併せ持つ。

それでも不採用とする理由:

1. **全期間で統計的に非有意** (p=0.138/0.847/0.299)。2025は実質ゼロ
2. **登録済み安全指標の市場top-kフロアが、baseline対比でも3期間すべてで悪化方向**。
   LogLossは改善するがtop-k的中は劣化する — 中位馬間の確率分布は鋭くなるが勝馬特定は
   改善しない、というパターンであり、WIN5運用が必要とする能力に対して負の証拠
3. **基準の一貫性**: 選抜有意 (p=0.005) だったT53をフロア悪化2/3期間で不採用にした以上、
   非有意+フロア悪化3/3期間の本候補は不採用以外にない

prospective評価 (T59e/T17時代) が実現した際の**最有力再訪候補**として記録する。
本番接続は行わない。**これでT61ロードマップ (T61a/T54a/T53/T54b-c-d) は全路線の裁定が完了**。
モデルは市場同等〜微劣後という認識に変更はない。
