# T61: 好走馬予測精度向上に向けた展望 — Fable 5×Codex 直接討議の収束記録

実施: 2026-07-23。T59と同形式で、Fable 5がCodex CLI (`codex exec`・read-onlyサンドボックス)
を直接呼び出し、人手を介さない討議を実施。**2往復で収束 (Codexが `CONVERGED` 宣言)**。
討議原文はローカル `.agents/agmsg-t61/` (親リポジトリ側・非コミット)。

## テーマ

「好走する馬」= 単勝1着に限らず複勝圏内・連対を含めた上位進入の予測精度。
T59 (買い目表示ロードマップ) は「単勝市場確率の校正」であり、**予測モデル自体
(conditional logit 21特徴量・T16複勝モデル) の精度向上とは別軸**。本討議は後者に絞った。

## 討議で確定した重要な事実誤認の訂正

Codexが当初提案した「係数非共有の連対・複勝圏専用モデル (第4路線)」は、
**Fable 5の指摘とCodex自身の再確認 (`SPEC-T16-web-place-model.md`・
`backtest_place_model.py:67-149`) により、3着内部分は既存T16 (2026-07-14採用済み)
そのものだったと判明・Codexが訂正**。T16は独立ロジスティック回帰・オッズ非依存
20特徴・Platt校正・7頭以下2着内ルールを既に備え、2025/2026H1とも現行Web主成分を
捕捉率・Brierで上回っている。**ただし比較対象は市場でなくWeb手動スコアであり、
市場超えでも馬券シグナルでもない** (T16採用時の限定どおり)。この事実により、
討議の論点は「新モデルを作る」から「T16の市場比較・拡張・統合」へ収束した。

## 合意事項

1. **低中コスト特徴探索は尽きた**。残る差別化要因は3系統: (a) T16の市場比較・
   拡張 (b) T53動的相手関係rating (c) T54展開予測
2. **T16の3着内部分は重複確認済み**。新規に開拓する価値があるのは
   **係数非共有のtop2 (連対) 専用モデル**のみ (T16bとして新規)
3. **T52型の共有学習 (win/place/showの多タスク学習) は再開しない**
   (T43の「順位情報が勝馬係数を汚染する」負の結果と同じ経路のリスク)
4. **T53 (動的相手関係rating)**: winner-onlyのPlackett-Luce top-1オンライン更新のみ
   (全着順BT/full PLは不使用、T43の再演を避ける)。ratingは最終予測にせず
   as-of特徴として既存モデルへ投入。分割は当面**全条件共通** (芝/ダート分割は
   標本半減・収束遅延のリスクがあるため、統一版の結果を見てから判断)
5. **T54a (既存データでの展開PoC)**: 新データ取得を待たず、既存 `ability.db.runs`
   の`c4`/`agari` (2021-25年全行充足・2026年99.5%充足) から**過去走のみで**
   事前脚質・想定先行頭数を推定する短期PoCを先行実施。**中間指標 (推定脚質と
   実現c4の相関) は診断用の副指標に留め、採否は最終top3/勝馬LogLossのみで行う**
   (T18の「表示値とML特徴量の混同」を戒めた教訓と同型の規律)
6. **T54b (JRA公式の無料データ拡張)**: JRA公式レース結果には全コーナー隊列・
   レース全体のハロンタイムが掲載されるが、馬別セクショナルタイムではなく、
   現DBにラップ列も無い。**T54aとは別のPoCとして、歴史coverage・パース安定性・
   馬番対応・as-of再現性を先に確認してから本体実験に進む** (T42/T50と同型の
   Stage 0規律)
7. **不採用のまま維持**: 単純アンサンブル (C3)・NDCG/pairwiseの主目的化
   (T43と不整合)・LightGBM即時再開 (T20、新特徴確定後)
