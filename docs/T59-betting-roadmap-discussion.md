## 合意事項 (全9項)

1. **目標の転換**: 「勝馬予測で市場に勝つ」を目標から外す (市場相対・低コスト特徴・
   観測データの3波が台帳付きで全滅した事実に基づく)。新目標は
   「**市場整合の確率エンジンを土台に、馬券種横断の価格の歪みを検出し、
   適切な買い目として表示する**」
2. **基礎確率は同一cutoffの単勝市場確率** (オッズ逆数正規化)。初期は確定オッズ、
   T17蓄積後に運用cutoff版を追加。**現行CLは基礎から降格し比較・シャドー専用**
   (Fable 5が当初主張したCL土台をCodexの反論で撤回 — 市場劣後のCLを土台にするのは
   「市場整合」と矛盾する)
3. **λは券種別でなく着順段階別 (λ2・λ3) を全券種で共有** — 複勝/ワイド/馬連/三連複は
   全て段階確率の合成で書け、自由度を2に抑えることでfalse positiveの温床を作らない
4. **初回スコープは複勝・ワイド・馬連**。三連複・三連単は第2波 (3着段階の統計とオッズ
   取得量の問題)
5. **3段階運用**: 表示のみ (推奨文言なし) → prospectiveシャドー → 事前登録ゲートを
   通過した券種のみ推奨表示。ワイドoverlay 66.6%の教訓を初期設計に織り込む
6. **歪み探索は3系統に限定**: プール間不整合 / 組合せ相関の誤価格 / ケントク買い。
   これ以外に探索空間を広げない
7. **T42 (調教データ) は終了** (ユーザー前提「課金なし」により。スーパープレミアム
   前提が成立しない)。勝率増分の探索はT17 (時点別オッズ・無料) のみ残す
8. **WIN5は現状凍結** (撤去しない・新規改善投資もしない。allocate_picks_probは
   市場同等確率でも機能する採用済みの仕組み)
9. **台帳規律**: 券種ごとに台帳を分け一次指標は各1つ (開催日ブロックOOSの券種別
   log loss、ベースラインはλ2=λ3=1の素朴Harville)。2024-26H1はhistorical benchmark
   であり推奨採用の根拠にしない。推奨ゲートは券種別判定 (連座させない)

## 討議で確定した事実 (Codexの棚卸し)

- **組合せ払戻の取得経路は既存**: `backfill_pay_netkeiba.py` →
  `race_payouts(date,place,r,bet_type,combo,pay)` に複勝・枠連・馬連・ワイド・馬単・
  三連複・三連単を保存済み (T31で1,083/1,083R・通信失敗0)
- ただし保存済みは**的中組合せの払戻のみ**。全組合せの発売オッズは未取得
  (`odds_snapshots` は単勝・複勝上下限のみ)
- **確率層の部品も既存**: `api/combo_probs.py` (λ冪Harvilleのワイド、λ=0.7を21-24で選択)、
  `backtest_combo.py` (馬連・ワイド)。券種別校正・複勝/三連複・表示UIは未実装
- **歴史単勝オッズは `runs.win_pay` に全馬分が符号化済み** (勝馬=払戻÷100、他馬=括弧付き
  オッズ、`backtest_win5.py` の `parse_final_odds()` が復元)。2026年分は同期済み・
  ほぼ完備だが、**2021-25の年別被覆率は未監査** → P0
