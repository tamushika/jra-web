## 多重性の扱い (選定と確認の分離)

- **現確認窓で実マネー移行資格を持つのはP1のみ** (既登録の5条件ゲート)
- P5/P3は推定専用 — 同一ゲート判定もBonferroni補正もしない (推定に検定を装わせない)
- 将来、採択した戦略/組合せは**別ID・新規prospective窓・事前固定ゲート**で確認してから
  実マネーへ (selection bias を確認窓に持ち込まない)

## 実装優先順・登録

P1稼働確認 (8/22) → P5 (`T70-virtual-betting-p5-v1`) → P3 (`T70-virtual-betting-p3-v1`)。
