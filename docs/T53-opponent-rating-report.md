# T53 動的相手関係補正ratingレポート

実装日: 2026-07-23  
状態: 評価ハーネス実装完了、T39事前登録待ち

## 固定実装

- 2018-01-01から2026-06-30まで、全条件共通の単一rating系列を日付順に1回通しで構築
- 各レースの事前ratingから `softmax(r_i)` を計算
- 更新はwinner-only PL-top1勾配 `winner_count_i − n_winners × p_i` のみ
- 2着以下の相対順位、着差、全順位PL、芝・ダート／距離別ratingは不使用
- 同着は全勝馬を同じ事前確率に対する複数top-1イベントとして集約し、現行CL尤度と一致
- 同日全レースは前日終了時点のratingを使用し、全レースの勾配と出走数を日末に一括反映
- 2018～2020はウォームアップ専用。特徴・学習・選抜・評価の出力対象は2021年以降

固定特徴は以下の2列のみ。

1. `opponent_rating_asof`: `r × n/(n+k)`。ただし事前出走数が5未満なら0
2. `opponent_rating_available`: 事前出走数が5以上なら1、それ以外0

## 固定評価グリッド

第1段はL2=`1.0`固定で以下の9候補を2024勝馬LogLossにより比較する。

- η: `{0.05, 0.1, 0.2}`
- 収縮k: `{5, 15, 40}`

第1段で選ばれたη・kだけを固定し、第2段でL2=`{0.3, 1, 3}`の3候補を確認する。baseline 21特徴もL2=`{0.3, 1, 3}`の3候補を併記する。追加構成や条件別ratingは探索しない。

分割は学習2021～2023、選抜2024。選抜後は2021～2024 final-refit版と2021～2023学習版を併記し、2025・2026H1へ固定適用する。

## 出力予定の副指標

- Brier、top-k、市場モデルとの同一母集団比較
- 2024・2025・2026H1のWIN5開催日paired block bootstrap
- 勝馬人気帯 `1–3 / 4–8 / 9+` ごとのcandidate−baseline勝馬LogLoss
- 各期間のrating利用可能率、平均、標準偏差、5/50/95%点
- n<5フォールバック群が0分散であること
- パックOFF時の基礎21特徴行列byte SHA一致

SPECのT39規約に従い、`T53-dynamic-opponent-rating-v1` のbase登録と封印ability.db SHA一致を、rating系列構築およびモデル評価より前に要求する。

現在の評価コマンドは次の理由で停止することを確認済み。

```text
T53 evaluation blocked: register T53-dynamic-opponent-rating-v1 in T39 ledger first
```

上位モデルによる登録後にのみ9+3候補とbaseline 3候補を実行し、結果JSONと本レポートへ数値を追記する。本番FEATURES、本番モデル、表示、通知、台帳は本実装では変更していない。

## 上位モデルレビュー追補 (2026-07-23, Fable 5)

**受理・独立検証済み**: `winner_only_gradient` の同着集約勾配式
(`winners − winner_count × p_i`) を手計算で検算し、`fit_conditional_logit` の
尤度 (同着を勝ち馬ごとに1イベント扱い) と数学的に厳密に一致することを確認
(m件の同着イベントの勾配総和 = `1{i∈勝者集合} − m×p_i` に一致)。

さらに3頭・6日分のトイレースを独立に手でシミュレートし (A/Bが交互に勝つ6走)、
`build_rating_feature_map` が返す2021年時点のas-of特徴値
`0.024956742167637918` が、Python標準ライブラリのみによる手計算結果と
**完全一致**することを確認した。日付原子性 (同日は前日終了時点のratingを使用し、
日末に一括反映) もコードを直接読解して確認済み。
