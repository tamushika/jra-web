# T53 動的相手関係補正ratingレポート

実装日: 2026-07-23  
状態: T39登録後の固定評価完了（採否は上位モデル）

## 固定実装

- 2018-01-01から2026-06-30まで、全条件共通の単一rating系列を日付順に1回通しで構築
- 各レースの事前ratingから `softmax(r_i)` を計算
- 更新はwinner-only PL-top1勾配 `winner_count_i − n_winners × p_i` のみ
- 2着以下の相対順位、着差、全順位PL、芝・ダート／距離別ratingは不使用
- 同着は全勝馬を同じ事前確率に対する複数top-1イベントとして集約し、現行CL尤度と一致
- 同日全レースは前日終了時点のratingを使用し、全レースの勾配と出走数を日末に一括反映
- 2018～2020はウォームアップ専用。特徴・学習・選抜・評価の出力対象は2021年以降

固定特徴は以下の2列のみ。

1. `opponent_rating_asof`: `r × n/(n+k)`。ただし事前出走数が5未満なら0
2. `opponent_rating_available`: 事前出走数が5以上なら1、それ以外0

## 固定評価グリッド

第1段はL2=`1.0`固定で以下の9候補を2024勝馬LogLossにより比較する。

- η: `{0.05, 0.1, 0.2}`
- 収縮k: `{5, 15, 40}`

第1段で選ばれたη・kだけを固定し、第2段でL2=`{0.3, 1, 3}`の3候補を確認する。baseline 21特徴もL2=`{0.3, 1, 3}`の3候補を併記する。追加構成や条件別ratingは探索しない。

分割は学習2021～2023、選抜2024。選抜後は2021～2024 final-refit版と2021～2023学習版を併記し、2025・2026H1へ固定適用する。

- 2024・2025・2026H1のWIN5開催日paired block bootstrap

## 上位モデル最終検証・裁定 (2026-07-23, Fable 5)

**受理・独立検証済み**: JSON全数値 (9+3候補・historical benchmark・人気帯別・rating分布) を
報告書と突合し完全一致を確認。8テスト+全体537テストパス。baseline候補がT54aと

### 詳細検証で判明した重大な事実

登録済み安全指標「人気帯別内訳」を自分で再集計したところ、**見かけの「3期間とも改善方向」
という一貫性は、薄い9人気以下バンドのアーティファクトだった**と判明した。

9人気以下 (n=34〜81、他バンドの1/10以下の標本) を除いた1-9人気の加重平均差分:

| 期間 | 全体 (含9+) | 9+除外 | 9+のみ (n) |
|---|---:|---:|---|
| 2024選抜 | -0.003304 (p=0.005) | **-0.002526** | -0.015718 (n=58) |
| 2025固定 | -0.000110 (p=0.935) | **-0.000203** | +0.000934 (n=81) |
| 2026H1固定 | -0.000363 (p=0.814) | **+0.000403** | -0.011041 (n=34) |

**2026H1は9+バンド除外後に符号が反転する** (改善→悪化)。つまり真にOOSな2026H1の
本体集団 (474R) では、T44/T50/T19/T58/T60/T54aと同型の「反転」パターンが起きている。
全体数値の見かけの改善は、わずか34レースの薄い長距離オッズ帯に依存していた
(roadmap §8「少数の高配当依存でない」ゲートが対象とする典型例)。

市場top-kフロア (k1) も確認: baseline自体が既に市場をわずかに下回るが (2024 -0.10pt,
2026H1 -0.99pt)、ratingを追加するとこの差がさらに拡大する (2024 -0.61pt, 2026H1 -1.58pt)。
2025のみ改善 (-0.30pt→+0.60pt、市場超え) だが期間横断で一貫しない。

### 裁定: 不採用 (負の結果)

**2024選抜の有意な改善 (p=0.005) は選抜集合自体の楽観バイアスを含み、真にOOSな
2025/2026H1では非有意かつ、人気帯分解後は2026H1で符号反転する。** これは
T44/T50/T19/T58/T60と同型の「選抜で見えた改善がホールドアウトで消える/反転する」
パターンであり、当初の「符号反転なし」という評価は人気帯別の検証不足による
見誤りだった (自己反省として記録する)。

一方で、T53は他の却下済み候補と1点異なる: 集約レベルでは3期間とも符号が保たれ、
実装・数式は完全に正しく、機構 (対戦相手の強さを介した動的評価) は構造的に新しい
情報源であり、既存特徴の焼き直しではない。**再挑戦の価値が完全に無いとは言えない**が、
現時点の証拠では本番採用の基準に届かない。

不採用理由:
1. 一次指標 (2024選抜) の有意性は選抜集合自体のものであり、単独では採用根拠にならない
   (プロジェクト全体の規律どおり)
2. 真のOOS期間 (2025/2026H1) は非有意。2026H1は登録済み安全指標 (人気帯別内訳) で
   検証すると9+バンド除外後に符号反転し、本体集団では悪化する
3. 市場k1フロアとの乖離がbaselineよりさらに拡大する期間が2/3ある
4. 改善の大部分が薄い長距離オッズ帯 (n=34-81) に由来し、roadmap §8の
   「少数の高配当依存でない」ゲートに抵触する
