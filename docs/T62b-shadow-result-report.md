## 4. 読み取り (計測事実のみ。採否はしない)

1. **一次指標の符号が歴史層から反転した。** 歴史層では選定レースでモデルが市場をわずかに上回っていたが、
   prospective 窓では下回っている (+0.016711)。95% CI [−0.019984, +0.051488] は 0 を跨ぐため
   「モデルが有意に劣る」とも言えないが、**歴史層で見えた優位は再現しなかった**。
2. **選定の付加価値が確認できない。** 選定 +0.016711 は未選定 +0.004923 より悪く、
   T62 の主張 (選定が優位を集中させる) と逆向き。
   ただし選定/未選定の paired 差検定は事前登録指標に含まれないため、**記述的比較にとどめる**。
3. **登録時の懸念④ (優位の 1-3 人気帯完全依存) が prospective でも再現した。** 選定レースのうち
   モデルが市場を上回るのは 1-3 番人気帯 (27 件・−0.038253) のみで、4-8 人気帯 (+0.125052) と
   9 番人気以下 (+0.217027) ではモデルが大きく劣る。これは T63 の「EV が高い帯ほどモデルは勝率を過大評価する」
   および 2026-07-13 の「市場のレース内序列に系統的な隙は無い」と整合する。
4. **懸念③ (選定率ドリフト) は解消方向。** 凍結閾値での実選定率は 17.8% で、設計値 20% におおむね復帰
   (歴史層でのドリフト懸念は 26%)。
5. 安全指標の市場 top-k フロアは k=1..4 すべて非悪化。ただし k=1,3,4 は市場と同値であり、
   「市場と同じ馬を選んでいる」ことの裏返しでもある。
