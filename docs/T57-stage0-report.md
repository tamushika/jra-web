## OCRと品質ゲート

ページごとにJSONを保存する再開可能な処理とし、JSON完結・非空・思考タグなし・5,000文字以下・期待source index一致を満たす出力だけを採用した。文章・表の相性に応じてローカルモデルをフォールバックし、最終分布は `qwen3.6:latest` 51ページ、`qwen3-vl:8b` 12ページ、`qwen2.5vl:7b` 1ページだった。

モデルの不確実申告を横展開し、目視不合格4ページに加えて同種の疑義があるページを含む計22ページを高容量モデルで再転写した。モデルが通常の表セルを不確実欄へ入れるノイズは集計から除き、`[判読不能]` の明示だけを未解決として数えた。
