## 特記事項

1. **道悪familyのみ3期間同符号の正** (+0.0079/+0.0028/+0.0277)。ただし完全に非有意
   (p_maxT=0.399) かつtop-kフロア不通過。T58人気薄帯と同じ「弱い残響」であり、
   ゲート緩和はしない。prospective専用の観察対象としても、現行の蓄積系 (T62b/T63) の
   人気帯・条件分解で無償に観測できるため、**専用の追加測定は起票しない**
2. **経験浅family (未勝利・新馬) は点推定でモデルが市場に劣後** — 「戦歴が薄いほど
   モデル有利」仮説は逆方向。市場は経験の浅い馬の評価でもモデルより正確
3. **C4 (ハンデ戦) の2026H1はハンデ判定0件** — 既知のソースドリフトどおり。
   設計どおり欠測として処理 (代替定義は発明していない)
4. セル別縮約順位の上位はC1 (芝道悪)・C3 (ローカル2勝) だが、いずれもfamilyゲートの
   不通過の内訳であり、単独有意はゲート外 (凍結どおり参考情報)

## 裁定への含意

事前登録stop rule「通過family 0なら不成立で終了しprospective SPECを起票しない」を適用。
**ユーザー提示テーマ (冬牝馬限定・ローカル2勝・道悪等) への回答**: 検証可能な形で
系統的に監査した結果、これらの特殊条件に市場効率の構造的な穴は検出されなかった。
「条件を絞れば勝てる」という直観は、この母集団とゲートの下では支持されない。

成果はセル別市場効率マップ (`outputs/t65_result.json` の cells/families 断面) として
恒久保存され、今後の同種の議論の一次資料になる。
