## 実装

`backtest_t63_ev_threshold.py` に、固定6閾値、2段階fail-closedゲート、
発走前最終の有効スナップショット選択、反実仮想EV、開催日block bootstrapを実装した。
台帳のグリッド・ゲート・prospective開始日と、SPEC／本番モデル／契約の3 SHAを
実行ごとに照合する。本番モデルSHAが変わった場合は集計せず再登録を要求する。

本番の `jra_ev.py`、通知関数、閾値1.3、ロギングDBには変更を加えていない。
