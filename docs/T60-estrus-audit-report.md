## 事前固定基準との照合

1. 前走3着内で主DiDが**負**かつp<0.10 → **不成立** (符号が逆・+0.007, p=0.69)
2. 人気帯横断で方向一致 → **不成立** (+0.020 / -0.008 / -0.019 と混在)
3. 非繁殖期プラセボで効果消失 → 判定対象なし (そもそも主効果なし。プラセボも同水準の
   ノイズ +0.016)

**判定: 3基準すべて不成立 → 本実験 (Stage B) に進まない。** サンプルは各セル2千〜1万超
あり、馬券に意味のある効果量を見逃す検出力不足ではない。

## 解釈

- 発情周期の機構が個体レベルで実在しても、**集団レベルの「中3週」符号には現れない**。
  性周期の位相は馬ごとにバラバラで、「前走が強いフェーズだった」個体を暦の間隔だけで
  選び出せない、が最節約的解釈 (書籍の例示 [フィリーズレビュー組・VM中3週] は
  距離設定・路線格の交絡が濃い)
- 前走4着以下での正のDiD (p=0.03) は事前基準外の10比較中の1つで、多重比較の
  ノイズとして扱う (追わない)
- 書籍由来仮説の顛末: T58直結グラフ=不採用、H2=監査で否定。**「機構がもっともらしい」
  ことと「市場がまだ価格に織り込んでいない」ことの間には大きな距離がある**、という
  本プロジェクトの一貫した教訓を追認
